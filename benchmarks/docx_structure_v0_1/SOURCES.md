# Research basis for DOCX Structure Gold Benchmark V0.1

The pilot cases are generated project data. The references below inform which WordprocessingML structural families and evaluation dimensions the pilot covers; no source document text is copied into the benchmark.

## WordprocessingML / OOXML structure

- Microsoft Learn — *Structure of a WordprocessingML document*  
  https://learn.microsoft.com/en-us/office/open-xml/word/structure-of-a-wordprocessingml-document

- Microsoft Learn — *Working with WordprocessingML tables*  
  https://learn.microsoft.com/en-us/office/open-xml/word/working-with-wordprocessingml-tables

- Microsoft Learn — Open XML Wordprocessing `SectionType` / section-break behavior  
  https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.sectiontype

These references motivate explicit coverage for the main document story, headers/footers, footnotes/endnotes/comments, native tables with rows/cells, and section boundaries.

## Document-structure evaluation precedents

- DocParser: Hierarchical Structure Parsing of Web Documents. It motivates evaluating document entities and hierarchical relations separately rather than using one opaque score.

- DocLayNet: A Large Human-Annotated Dataset for Document-Layout Analysis. Its diverse-source and explicit annotation-guideline approach motivates separating a small generated pilot from later human-reviewed real-document evaluation.

- Document parsing/layout benchmarks commonly separate content fidelity, element/layout classification, and hierarchy/reading-structure quality. V0.1 follows the same principle: metrics are reported by structural axis instead of collapsing everything into one number.

## Benchmark provenance

All pilot DOCX text and OOXML packages are generated by this repository. The generator records its id, fixed seed, deterministic ZIP policy, and exact SHA-256 for each case.
